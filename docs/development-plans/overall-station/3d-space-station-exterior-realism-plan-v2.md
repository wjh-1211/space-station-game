# 中国空间站外部真实感重制计划 V2

## 1. 本次调整结论

当前 Three.js 程序化灰盒已经验证了“外部总览 -> 点击舱段 -> 场景切换”的交互闭环，但它不应继续作为最终外观模型。用户提供的 `中国空间站俯瞰图.jpg` 显示了真实中国空间站组合体的关键构型：

- 天和核心舱位于中央纵向主轴；
- 问天实验舱和梦天实验舱从核心舱左右两侧横向连接；
- 左右展开的大型太阳翼是外观识别重点，不能用随机矩形板代替；
- 核心舱上下方还有较小的太阳翼、对接口、天线和外部设备；
- 舱体、节点、设备箱、热控表面和太阳翼的材质层次需要被保留。

因此项目调整为：

```text
资料与参考图核验
  -> Blender 外部全组合体建模
  -> 真实材质、太阳翼、机械臂和设备补齐
  -> 真实地球背景与光照
  -> GLB 导出与网页接入
  -> 外部环绕、缩放、热点和标签验收
  -> 外观通过后再设计三个舱段内部
```

## 2. 本阶段目标与边界

### 2.1 目标

本阶段只追求一个结果：浏览器中能够从多个角度看到一个外观上可辨认为中国空间站天宫组合体的 3D 场景，并且所有需要点击的舱段和部件都已经在外部模型中就位。

外部模型至少包含：

1. 天和核心舱主舱体、前后节点和可见对接口；
2. 问天实验舱完整舱体、设备箱、太阳翼连接结构；
3. 梦天实验舱完整舱体、设备箱、太阳翼连接结构；
4. 中央节点与三舱连接关系；
5. 左右四组大型太阳翼及其支撑、转轴和分片纹理；
6. 核心舱方向的小型太阳翼/电源阵列；
7. 公开资料可确认的机械臂、天线、外部载荷/实验平台和热控细节；
8. 真实地球球体、云层、昼夜材质和大气边缘效果；
9. 三个舱段的可点击热点、空间标签和相机目标。

### 2.2 明确不做

- 本阶段不制作可行走内部场景；
- 不把俯瞰参考图直接作为 3D 模型贴图；
- 不使用来源不明的网络 GLB 作为最终资产；
- 不凭想象增加未被资料支持的飞船、舱段或复杂外部设备；
- 不把游戏规划内容描述成中国空间站官方工程复原。

内部三舱方案在外部验收通过后另开 V4 计划，内部布局必须逐项标注“公开资料依据”或“游戏规划”。

## 3. 参考图与真实性基准

### 3.1 本地参考图

- 文件：`中国空间站俯瞰图.jpg`
- 用途：只作为构型、相对位置、太阳翼数量和外观分区的视觉基准；不作为贴图或法线来源。
- 对照角度：先复刻俯视轮廓，再用斜视和环绕镜头检查模型是否在三维空间成立。
- 新增主视觉参考：`中国空间站图片复刻.jpg`；用于校准 T 字轮廓、四组大型太阳翼、核心舱横向阵列、白色热控外观、设备密度和明亮地球构图。
- 新增图片属于用户提供的视觉复刻资料，只作为外观目标；舱段尺寸和工程细节仍需与 A/B 级公开资料交叉验证。

### 3.2 资料等级

| 等级 | 用途 | 处理方式 |
|---|---|---|
| A | 国家航天局、中国载人航天工程网等公开结构资料 | 可作为外部结构事实依据 |
| B | 官方公开视频、公开照片和科普图 | 可用于外观、材质和设备形态近似 |
| C | 新闻图片、用户提供参考图 | 只用于构型比对，需与 A/B 资料交叉验证 |
| D | 未验证的模型、论坛图和 AI 图 | 不作为最终资产依据 |

每个重要部件在 `references/space-station-sources.md` 中记录来源、访问日期、支撑的对象和不确定点。无法确认的细节采用低对比度近似，不制作带有事实含义的虚假标识。

## 4. 外部模型拆分

### 4.1 Blender 集合

```text
OVW_Station_Assembly
├── STA_Tianhe_Exterior
├── STA_Wentian_Exterior
├── STA_Mengtian_Exterior
├── STA_Central_Node
├── STA_Docking_Ports
├── STA_Solar_Array_Large_L
├── STA_Solar_Array_Large_R
├── STA_Solar_Array_Small_L
├── STA_Solar_Array_Small_R
├── STA_Robotic_Arms
├── STA_Antennas_And_External_Equipment
├── HOTSPOT_Module_Tianhe
├── HOTSPOT_Module_Wentian
└── HOTSPOT_Module_Mengtian
```

外部壳体、细节网格、热点代理和碰撞网格分开导出。网页交互只依赖 `moduleId`，不依赖具体网格名称，这样后续替换细节不会破坏点击逻辑。

### 4.2 建模层级

采用三层资产，避免一开始陷入不可验收的微小细节：

1. **L0 构型层**：准确的三舱关系、轴向、太阳翼展开方向和整体比例；
2. **L1 识别层**：舱体端盖、环带、设备箱、对接口、机械臂和支撑结构；
3. **L2 材质层**：热控多层材料、白色涂层、深色太阳能电池片、金属边框、标签与连接件。

只有 L0 通过俯视和斜视复核后，才进入 L1；只有 L1 通过外观识别复核后，才制作 L2 和优化拓扑。

## 5. 尺寸、坐标与命名规范

- Blender 使用米制单位，Z 轴向上；
- 天和、问天、梦天尺寸以已登记公开资料为比例基准；
- 统一定义空间站组合体原点和主轴，禁止各舱段单独任意缩放；
- 导出前应用旋转和缩放，保留对象原点及可读名称；
- 三个热点设置 `userData.moduleId`：`tianhe`、`wentian`、`mengtian`；
- 太阳翼、机械臂和设备使用独立对象或集合，便于网页端按需显示与调试；
- 当前 GLB 保存为 `public/models/station-exterior-v3.glb`，源文件保存为 `public/models/station-exterior-v3.blend`。

## 6. 真实地球方案

### 6.1 视觉组成

地球不再使用当前的简化地平线占位，改为以下可控层：

- 地球球体：昼面使用公开授权的真实地球纹理；
- 云层球：半透明云纹理，略高于地表并缓慢自转；
- 夜面：在需要时叠加低强度城市灯光纹理；
- 大气层：基于 Fresnel/Shader 的蓝色边缘散射，避免厚重蓝色光环；
- 光照：太阳方向光与地球环境光分离，空间站受光方向与地球昼夜一致。

纹理优先从 NASA Visible Earth、NASA Blue Marble 或同等可追溯公开来源获取，并在资产清单记录授权和分辨率。地球贴图只表现背景真实感，不承担空间站交互逻辑。

### 6.2 性能策略

- 默认加载中等分辨率纹理，桌面高性能设备再启用高清版本；
- 地球云层和城市灯光可按质量档位关闭；
- 外部 GLB 使用 Draco/Meshopt 压缩前后都保留可回退版本；
- 地球不做过度高面数，优先使用材质和大气 Shader 表现曲率。

## 7. 网页交互目标

保留现有交互闭环，但将进入内部动作延后：

```text
外部真实感总览
  -> 环绕/缩放
  -> 悬停舱段，模型与文字同步高亮
  -> 点击天和/问天/梦天
  -> 镜头聚焦对应外部入口和舱段
  -> 显示外部结构信息面板
```

本阶段点击后显示“外部结构信息”或“内部内容待建设”，不显示当前低保真内部灰盒作为最终体验。内部场景待外观资产验收后接入，以免用户把灰盒误认为真实舱内布局。

### 7.1 真实时间比例的轨道运动

- 采用代表性近地圆轨道周期 `92 分钟/周`，轨道角速度为 `360 / 5520 ≈ 0.065217°/秒`；
- 物理基准仍为 `92 分钟/周`，展示层按用户要求采用明确标注的 `12×` 演示速度；浏览器中一周约 `7 分 40 秒`；
- 采用空间站随动坐标系：空间站保持在交互中心，地球表面按“轨道角速度 - 地球恒星自转角速度”从下方掠过，星空和太阳方向按轨道相位变化；
- 地球恒星自转周期采用 `23:56:04.0905`；
- 轨道相位使用墙上时间计算，不做逐帧角度累加，帧率变化、后台标签页暂停后仍保持连续；
- 界面显示 `12×`、轨道相位和真实基准周期，避免把加速展示误认为实时速度。相位是本次页面会话的模拟相位，不代表空间站当前真实经纬度；
- 本阶段不接入 TLE/SGP4，不模拟轨道摄动、姿态控制和实时在轨位置，因此称为“代表性真实时间比例”，不称为实时数字孪生。

## 8. 资产验收门槛

外部版本只有同时满足以下条件，才允许进入内部设计：

- [ ] 俯视轮廓与参考图中的中央轴、左右实验舱和太阳翼关系一致；
- [ ] 斜视角下三舱仍能被正确识别，没有穿插、悬空或任意镜像；
- [ ] 四组大型太阳翼、小型太阳翼和支撑结构位置有资料依据；
- [ ] 舱体颜色、太阳能电池片、热控材料和金属件具有可区分层次；
- [ ] 地球不是纯色球体，昼夜、云层和大气边缘可见且不遮挡空间站；
- [ ] 三个热点命中正确舱段，环绕、缩放、刷新和窗口变化稳定；
- [ ] 轨道相位以 92 分钟物理周期为基准、按明确标注的 12× 演示速度连续推进，后台恢复后不丢失经过时间；
- [ ] GLB 在 Blender、glTF 查看器和浏览器中外观一致；
- [ ] 资产清单记录来源、授权、版本、导出 Blender 版本和最后检查日期；
- [ ] 未确认内容已标注为近似或游戏规划。

## 9. 风险与处理

| 风险 | 处理 |
|---|---|
| 参考图是单一俯视角，无法证明所有背面细节 | 只把它作为构型基准，背面细节必须找 A/B 级资料或降低细节承诺 |
| 真实网络模型授权不清 | 不直接使用，改为依据公开资料在 Blender 自建；需要外部资产时先登记许可证 |
| 细节过多导致网页卡顿 | L0/L1/L2 分层、LOD、纹理压缩和独立加载 |
| 地球纹理来源不明或太大 | 使用 NASA 等可追溯来源，并保留中等分辨率回退版本 |
| 外部模型与旧灰盒坐标不一致 | 保持模块 ID 和相机配置接口，导出后做坐标校准，不修改交互契约 |

## 11. 完成定义

用户打开网页后，第一眼看到的应是完整的中国空间站外部组合体，而不是三根简单圆柱。用户可以旋转、缩放并从俯视和斜视角确认中央核心舱、左右实验舱、太阳翼、机械臂和地球背景；点击三个舱段时，系统能稳定识别对应对象。完成以上外部验收后，才开始内部具体构想。
