# 中国空间站高保真外部重建计划 V3

## 目标

将现有 V3 的“可辨识近似”升级为以完整三舱长期在轨构型为基线、以公开多视角资料为约束的高保真网页资产。验收标准是：在固定正视、斜视、侧视和近景镜头中，外观结构、太阳翼拓扑、天和/问天/梦天差异和材质层次均能与官方公开资料对应。

本计划追求公开可见外观的照片级观感，不声称未公开部位的 1:1 工程真实性，也不将模型称为官方 CAD 或实时数字孪生。

## 建模基线

- 天和：`16.6m` 长、最大直径约 `4.2m`；前端节点舱、生活控制舱、资源舱以及核心舱太阳翼；
- 问天、梦天：各 `17.9m` 长、最大直径约 `4.2m`；两者从结构与设备上明确区分，不能共用镜像细节；
- 默认不显示神舟、天舟等临时来访飞行器，避免把特定任务状态误认为稳定构型；
- 资料、用途与限制见 `references/official-high-fidelity/README.md`。

## 资产层级

1. **H0 结构**：按图纸比例重建节点舱、三舱分区、对接口、六组太阳翼与核心支撑；
2. **H1 识别**：为天和、问天、梦天分别建立气闸/货物气闸、外部载荷、机械臂基座、舱门、扶手和天线；
3. **H2 表面**：制作白色热控层、金色 MLI、深蓝电池片、边框、接缝、紧固件和低强度法线细节；
4. **H3 交付**：高模烘焙为网页 GLB，保留简化射线热点和 LOD 回退，不把高面数细节用于点击检测。

## 技术路线

- Blender 5.2.3 通过 `tools/build_station_exterior.py` 生成 `station-exterior-v4.blend/.glb`；
- 所有高可见度对象使用具名集合和明确部件前缀，保留 `moduleId` 交互契约；
- 小型重复零件采用实例化/程序化阵列，导出前控制网格数量和 GLB 体积；
- PBR 材质采用独立颜色、粗糙度与法线层；真实参考图仅用于核验，不嵌入发行文件；
- 网页只加载中等细节 GLB，近景细节由烘焙贴图与材质微纹理承担。

## 分阶段验收

| 阶段 | 完成条件 |
|---|---|
| R1 资料锁定 | 官方多视角资料归档，构件清单与不确定项建立 |
| R2 H0/H1 | 三舱外形各不相同，节点、翼面、气闸/货物气闸与外部平台均可辨认 |
| R3 H2 | 材质不再是单一灰色，近景可见真实热控/电池/金属层次 |
| R4 Web | V4 GLB 加载稳定，热点、标签、轨道、桌面和手机构图不回归 |
| R5 审核 | 四个固定视角与参考清单逐项核验，未确认部位显式记录 |

## 完成定义

用户在默认总览和近距离环绕时，能看到一个由可区分的天和、问天、梦天组成的完整中国空间站：有真实比例的多端口节点、不同的气闸与外载荷结构、六组正确拓扑太阳翼、舱外机械臂/扶手/天线/MLI 等细节，并且网页交互和性能保持稳定。
