# 天和核心舱内部复现开发计划

## 目标

以公开资料和用户提供的“带大家参观中国空间站内部”视频为观察依据，直接完成天和核心舱一个可进入、可观察、可交互的真实感第一人称场景。第一阶段就要求真实的舱壁面板、扶手、设备柜、线缆、睡眠区、灯光和材质，不把灰盒作为交付目标，也不把未公开的工程细节伪装成官方结构。

## 交付策略：真实场景垂直切片

第一阶段选择视频中最清晰、最容易复核的一段内部空间作为完整垂直切片：从圆形入口/节点方向进入，沿长向舱体看到连续白色面板、蓝色扶手和两侧设备带，最终抵达睡眠区。这个切片必须从一开始就包含真实感几何、材质、灯光、设备外形和第一人称交互；后续再沿同一坐标系扩展到就餐、通信、锻炼和医监区域。

垂直切片的完成标准是“拿视频截图对比时，画面构图、材质层次、设备密度和可移动方向都能对应”，而不是“先放几个方块验证流程”。任何临时占位几何只能存在于开发分支的短期调试中，不得作为阶段成果或最终展示。

## 视频逐帧工作流

脚本使用 Chrome 的视频解码器，按指定采样率将每一帧导出为 JPEG，并生成 `manifest.json`：

```powershell
node tools/extract-video-frames.cjs `
  references/source-material/tianhe/interior-video/xiaohongshu-tianhe-interior.mp4 `
  references/source-material/tianhe/interior-video/frames-30fps `
  30
```

调研阶段可以先用 `2` 或 `5` fps 快速浏览；需要逐帧对照时使用 `30` fps。导出的帧属于本地参考资料，目录被 `.gitignore` 忽略，不应直接提交到 GitHub。

本次视频已经完成全量导出：`809` 帧、`26.935` 秒、`30` fps。快速审查帧位于同级的 `frames-1fps/`，完整逐帧资料位于 `frames-30fps/`。

## 已确认的公开功能分区

中国载人航天工程网公开资料将天和核心舱密封舱内划分为六类区域：

1. 工作区：任务操作、通信和实验支持；
2. 睡眠区：独立睡眠环境和个人收纳；
3. 卫生区：卫生设施与隐私隔断；
4. 就餐区：微波炉、冰箱、饮水机、折叠桌等；
5. 医监医保区：健康监测和医疗保障设备；
6. 锻炼区：太空跑台、太空自行车、抗阻拉力器。

公开资料还提到情景照明可由手机 App 控制，具备航天员之间及天地之间的语音/视频通信能力，并支持电子邮件通信。上述内容可以作为第一批面板交互的事实依据；面板的具体品牌、按钮布局和线缆走向，若视频或公开图像无法确认，只做低细节游戏化近似。

## 视角与空间表现

### 摄像机

- 默认第一人称，眼高不固定，采用“漂浮在舱体中心线附近”的相机；
- 允许 6DoF 观察：前后、左右、上下平移以及俯仰/偏航/滚转；
- 进入舱段后保留轻微相机漂移和惯性，避免像地面 FPS 一样有固定脚底；
- 通过可见扶手、舱门圆环和设备边缘建立方向感。

### 微重力交互

- 默认没有重力加速度，松手后保持速度并逐渐阻尼；
- 抓住扶手后沿舱体轴线移动，释放时保留一小段惯性；
- 推离墙面/设备可产生可控反作用速度；
- 重要交互物体使用吸附/软约束，防止用户把关键面板推离场景；
- 设置“演示模式”：自动沿预设路径漂浮，便于第一次体验和视频录制。

## 建模拆分

1. `H0 真实舱体`：节点舱、大小柱段、后端通道、资源舱及连接门，按视频视角建立可进入的内部空间；
2. `H1 真实内装`：白色/浅灰面板、圆角过渡、接缝、检修盖、地板/顶板设备带、舱门和隔断；
3. `H2 真实设备`：照明、通信终端、折叠桌、收纳柜、摄影机、睡袋、锻炼设备和医监设备；
4. `H3 可交互实体`：真实几何上的面板热点、状态卡、按钮反馈、灯光状态、门/桌/隔断动画；
5. `H4 真实感氛围`：微弱漂浮尘埃、设备风扇声、提示音、低频结构震动、舱内灯光和地球反照光。

## 细节不遗漏检查表

- [ ] 舱壁/顶板/地板的连续白色面板、接缝、圆角和检修盖；
- [ ] 蓝色扶手、固定带、脚部约束点和可抓取的环形结构；
- [ ] 左右设备带的柜体层级、黑色/灰色接口、线缆和管路；
- [ ] 顶部蓝色设备盒、照明灯、传感器和悬挂件；
- [ ] 摄影机本体、镜头筒、支架、连接线和旁侧控制面板；
- [ ] 睡眠区的白色睡袋/软垫、固定带、圆形中心接口和周边扶手；
- [ ] 舱门/节点区域的圆形框、护栏、转接环和进入方向；
- [ ] 设备材质的哑光白、浅灰金属、蓝色软质件和少量黑色面板；
- [ ] 真实画面中的遮挡、反光和低清区域不得被擅自补成“确定结构”；
- [ ] 每一项新增高可见度细节至少关联一个视频时间码或一条 A 级公开资料。
